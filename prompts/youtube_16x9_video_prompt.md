# 유튜브 16:9 인포그래픽 영상 제작 프롬프트 (마스터)

> 아래 전체를 복사해서 새 대화에 붙이고, 맨 아래 `[입력]`에 음성 파일과 대본만 바꿔 넣으면 같은 스타일의 영상이 만들어집니다.

---

## 0. 한 줄 요약
음성 파일 + 대본을 받아서, **1920×1080(16:9) 유튜브 영상**을 만든다. 밝은 미니멀 톤의 인포그래픽 + 밈 + 직접 만든 UI 화면으로 대본 내용을 시각화하고, 챕터 타이틀 카드와 챕터 진행바를 넣고, 자막은 하단 중앙에 한 문장 이내로 띄운다. 효과음·화면전환 효과는 넣지 않는다.

---

## 1. 출력물
1. **영상**: 1920×1080, 30fps, H.264(yuv420p, CRF 20) + AAC 192k, 음성은 원본 그대로(볼륨 가공·배경음악·효과음 없음)
2. **썸네일**: 1280×720 PNG
3. **유튜브 설명란용 챕터 타임스탬프** (실제 음성 기준 시간, 첫 줄은 0:00)
4. 결과 파일은 레포에 커밋·푸시

## 2. 음성 처리
- 음성 파일이 구글 드라이브 공유 폴더 링크면 `gdown --folder <링크>`로 받는다.
- 음성은 **편집하지 않는다** (자르기·속도·볼륨·노이즈 처리 없음).
- 음성 인식: `faster-whisper large-v3-turbo`, language=ko, word_timestamps=True, beam_size=5, initial_prompt=대본 앞부분.
- 자막 텍스트는 **인식 결과가 아니라 대본 원문**을 쓰고, 인식 결과는 타이밍에만 쓴다.
  - 대본 글자와 인식 글자를 글자 단위로 정렬(difflib)해서 각 자막 줄의 시작/끝 시간을 구한다.
  - 시작 시점은 파형 RMS(10ms)로 찾은 실제 발화 시작점에 맞춘다(무음 뒤 줄은 다음 onset으로, 아닌 줄은 ±0.15초 내 onset으로 스냅). 자막은 0.03초 먼저 띄운다.
  - 다음 줄과 0.6초 미만 간격이면 자막을 계속 유지(깜빡임 방지), 그 이상이면 끝+0.2초에 내린다.
  - 녹음과 대본이 다른 단어는 **녹음 기준**으로 맞추고, 무엇을 바꿨는지 보고한다.

## 3. 자막 규칙
- 위치: **화면 하단 중앙 고정** (상단 기준 y≈880px).
- 스타일: 검정(#141414, 94% 불투명) 둥근 박스(반경 14px) + 흰 글자, Gothic A1 Bold 56px, 줄간격 1.3, 최대 폭 1500px, 단어 단위 줄바꿈(keep-all).
- **한 화면에 한 문장을 넘기지 않는다.** 긴 문장은 쉼표·구·절 단위로 의미가 끊기지 않게 나눈다(대략 한 화면 12~28자, 최대 2줄).
- 마침표는 지우고, 따옴표·물음표는 살린다.
- 핵심 문장(대본에서 `**`로 표시했거나 영상의 결론 문장)은 **주황 박스(#FF5A1F)**로 강조. 크기는 동일.
- 폰트는 Gothic A1(Medium/Bold/Black) 한 가족 + 이모지용 Noto Color Emoji만 쓴다.

## 4. 디자인 시스템
- 캔버스: 1920×1080
- 배경: 따뜻한 오프화이트 `#F5F3EE` + 아주 옅은 90px 격자선(검정 3.5%)
- 색: 잉크 `#141414`, 보조 회색 `#8C877E`, 선 `#E4DFD5`, 포인트 주황 `#FF5A1F`, 긍정 초록 `#12A150`, 카드 흰색
- 카드: 흰 배경, 반경 26px, 옅은 그림자(0 14px 40px rgba(0,0,0,.08)), 2px `#EEEAE2` 테두리
- 강조 카드: 검정 배경 + 흰 글자 + 주황 포인트
- 섹션 제목(카드 위): 왼쪽에 주황 세로 막대 + 44px 텍스트
- 아직 나오지 않은 요소는 **흐리게(opacity 0.18)** 미리 보여주거나 자리만 잡아두고, 나레이션이 그 내용을 말하는 순간 켠다.
- **화면 전환 효과 없음**(컷 전환), **효과음 없음**, 등장 애니메이션 없음. 예외: 막대그래프는 0.9초 동안 자라는 정도만 허용.
- 콘텐츠 영역: 화면 중앙(상단 기준 y=505 중심, 1740×640 박스). 자막과 겹치지 않게.

## 5. 상단 헤더 (챕터 표시)
- 왼쪽 위(x=90, y=46): 검정 라벨 `CHAPTER n` + 챕터 제목(38px)
- 그 아래 챕터 수만큼의 진행바: 지난 챕터는 검정, 현재 챕터는 주황, 남은 챕터는 회색
- 오프닝 구간과 챕터 타이틀 카드가 떠 있는 동안에는 헤더를 숨긴다.

## 6. 챕터 타이틀 카드 (모든 챕터 시작점에 고정 적용)
- **전부 중앙 정렬, 심플하고 고급스럽게.**
- 배경: 중앙이 살짝 밝은 다크 라디얼 그라데이션(#232220 → #121212)
- 위에서부터:
  1. `—— CHAPTER ——` : 26px, 자간 12px, 웜그레이(#9C958A), Medium, 양옆 가는 선(70px, #4a4742)
  2. 번호 `01`~ : 150px, Medium(얇게), 주황, 자간 4px
  3. 가운데 짧은 선: 56×3px, 흰색 35%
  4. 챕터 제목: 78px, Bold, 흰색, **한 줄**
- 전체 블록은 화면 중앙보다 약간 위(하단 패딩 170px)로 올려 하단 자막과 겹치지 않게.
- 챕터의 첫 문장이 시작될 때 띄우고, 다음 문장(1~3초 후)에서 본문 화면으로 넘어간다. 1초 미만으로 너무 짧으면 다음 장면 시작을 한 문장 뒤로 미룬다.
- 마무리(정리) 구간은 타이틀 카드 없이 바로 "오늘의 정리" 화면으로.

## 7. 장면 구성 원칙
- 대본의 문장/문단마다 그 내용을 가장 잘 보여주는 화면을 하나씩 배정한다(7분 영상 기준 약 70~80장면).
- 장면은 **해당 문장이 시작되는 순간 바뀐다**(자막과 정확히 동시에).
- 장면 안의 세부 요소(목록 항목, 비교 카드의 오른쪽, 표의 칸, 말풍선, 체크 표시)는 **나레이션이 그 단어를 말하는 순간** 켠다.
- 대본의 `[화면]` 표시는 그 내용 그대로 직접 만들어 넣는다. `(예시)` 표시는 화면 제목에 "(예시)"를 붙인다.
- 실제 사용자 아이디·개인정보는 절대 넣지 않는다(댓글 아이디는 회색 막대로 가림).
- 비율 가이드: 인포그래픽·UI 화면 약 80%, 밈 약 15%, 큰 문구 카드 약 5~10%.

## 8. 인포그래픽 컴포넌트 목록 (필요에 맞게 골라 쓰기)
| 컴포넌트 | 언제 | 모양 |
|---|---|---|
| **잠금 타일(lock)** | 무엇/왜/어떻게 같은 3단 구분 | 카드 3장: 단어(92px) + 영문 소문구 + 이모지(✅/🔒) + 상태 알약(무료/상담). 유료 카드는 검정+주황 |
| **목록(list)** | 오늘 다룰 내용, N가지, 정리 | 번호 원 + 항목 카드. 현재 항목만 검정 강조, 나머지 흐리게 |
| **비교(vs)** | A vs B, 전/후, ✕ vs ○ | 카드 2장(왼쪽 흰색, 오른쪽 검정 강조), 이모지 130px, 가운데 `≠`, `=`, `+`, `or` 가능 |
| **표(table)** | 두 대상의 여러 항목 비교 | 3열(항목/A/B), 이긴 쪽 주황 굵게, 칸마다 나레이션 시점에 등장 |
| **흐름도(flow)** | 단계·순서·인과 | 가로 카드 + `→` 화살표, 마지막 단계 검정 강조, 하단 주의 메모(연주황 배경) 가능 |
| **큰 문구(big)** | 핵심 주장, 반전 | 92px 굵은 문구 + 아래 검정 박스 문구(t2)가 나레이션 시점에 등장, ✕/○ 활용 |
| **댓글창(comments)** | 반응·댓글 묘사 | 인스타 댓글 UI, 아이디는 회색 막대로 가림, 하트, 하나씩 달림 |
| **DM 받은편지함(dm)** | 문의 없음 | 메시지 탭 UI + 📭 + "문의 0건" |
| **프로필(profile)** | 계정 묘사 | 프로필 사진·게시물/팔로워 수·게시물 그리드 + 초록 배지("✓ 꾸준한 업로드") |
| **막대그래프(bars)** | 수치 대비 | 2개 막대(검정 vs 주황), 0.9초 동안 자람 |
| **갈래도(branch)** | 같은 고민 → 다른 원인 | 상단 검정 말풍선 + 아래 카드 3장(사람/이모지/문제/주황 해결 라벨) |
| **격자(grid)** | N명 × M가지 시도 | 사람별 1~5 칸 → 시도(회색) → 맞는 것 ✓초록, 나머지 ✕연주황 |
| **예시 카드(example)** | 업종별 무료 vs 유료 예시 | 제목 + 좌우 카드(무료 콘텐츠=흰색 초록 태그 / 유료 상담=검정 주황 태그) |
| **캡션 카드(caption)** | 캡션·문구 Before/After | BEFORE(회색 태그)/AFTER(초록 태그) + 줄 단위 등장, 결론 줄은 주황 |
| **답글 스레드(thread)** | 댓글 응대 예시 | 질문 말풍선 → 나쁜 답(취소선+“✕ …”) → 좋은 답(검정+“○ …”) |
| **체크리스트(check)** | 점검 항목 | 체크박스 + 항목, 체크 시 결과 문구(주황 →) |
| **엔딩(end)** | 마무리 | “💬 궁금한 점은 댓글로” 검정 알약 + “구독하고 다음 영상 보기” 빨강 알약 |

## 9. 밈 사용 규칙
- 출처: imgflip 템플릿. 검색: `https://imgflip.com/memesearch?q=키워드` → `/meme/{ID}/...`의 ID를 **36진수로 변환**한 값이 이미지 파일명 → `https://i.imgflip.com/{base36(ID)}.jpg`(.png).
- 영어 글씨가 있는 템플릿은 가급적 피하고, 필요하면 빈 말풍선 위에 한국어를 직접 얹는다.
- 여러 칸짜리 템플릿은 필요한 칸만 잘라 쓴다(흰 여백은 자동 트림).
- 화면: 흰 테두리(8px) + 둥근 모서리(18px) + 그림자, 최대 1100×540 안에 비율 유지.
- 밈 위에 한 줄 캡션(작은 따옴표 ‘ ’, 44px)으로 “이 장면의 속마음/상황”을 한국어로 붙인다.
- **같은 영상 안에서 같은 밈 재사용 금지**, 드레이크 밈은 쓰지 않는다.
- 밈은 “감정·반응”이 필요한 순간에만(포기, 당황, 혼란, 의심, 자기만족, 후회 등). 정보 전달 장면엔 인포그래픽을 쓴다.
- 이번 영상에서 쓴 예: tip hat(감사 인사 후 떠남), Ight imma head out(거래 종료), 해골 대기(“나중” 기다림), 수학 계산 여인(막힘), This is fine(양쪽 다 잃음), 잠옷 소년(“영상에서 봤는데요?”), 닉 영 ???(가격 의문), 컴퓨터 앞 슬픈 페페(5개 다 했는데), 소리치는 여자(반론), 갤럭시 브레인(깨달음의 깊이), 의심하는 디카프리오(숨기는 거 아님?), 덤불로 사라지는 호머(갈 곳 없는 질문).

## 10. 이모지 사용 규칙
- Noto Color Emoji로 렌더링. 카드의 핵심 아이콘으로만 쓰고(카드당 1개), 본문 문장 속엔 남발하지 않는다.
- 의미 고정: ✅ 무료/가능, 🔒 유료/잠금, 👋 인사, 💳 결제, 🔖 저장, 📭 문의 없음, 🔍 진단, 💊 처방, 🎲 추측, 📋 점검표, 🩺 진단 상담, 💬 댓글, 💡 깨달음, 📚 정보의 양, 🙋 고객, 👀 구경꾼, 📉 가격 하락.

## 11. 썸네일 (1280×720)
- 같은 오프화이트 + 격자 배경.
- 왼쪽: 검정 태그(주제 2~4단어) → 3줄 헤드라인(88px Black, 핵심 2~4글자에 비스듬한 주황 형광펜 + 흰 글자) → 회색 부제 1줄.
- 오른쪽: 영상 핵심 구조를 카드 3장으로(예: 무엇 ✅ 무료 / 왜 ✅ 무료 / 어떻게 🔒 유료, 마지막 카드는 검정 강조).
- 글자는 줄간격 1.3 이상(형광펜이 윗줄·아랫줄과 겹치지 않게).

## 12. 렌더링 방식
- 장면 데이터(타임라인 JSON: 자막 줄, 장면 목록, 챕터, 요소별 등장 시간)를 만든 뒤,
- HTML/CSS 템플릿 한 장을 Playwright(Chromium)로 1920×1080 뷰포트에서 열고, `renderAt(t)`로 30fps 각 프레임을 그려 JPEG(품질 93)로 저장,
- ffmpeg로 프레임 + 원본 음성을 합쳐 MP4로 만든다.
- 완성 후 여러 시점의 프레임을 뽑아 겹침·잘림·빈 화면이 없는지 확인한다.

## 13. 마지막 보고 형식
1. 결과 파일 경로(영상/썸네일)
2. 녹음과 대본이 달라서 바꾼 부분
3. 챕터별 주요 화면 표
4. 유튜브 설명란 챕터 타임스탬프 코드블록
