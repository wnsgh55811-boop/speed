# 이다사 VOD 3강 — 나는 무엇을 좋아하는 사람인가

PPT 22장 + 최종 스크립트 + FishAudio 나레이션(9:08) + PPT 16번 슬라이드 BEFORE/AFTER 영상으로 만든 강의 영상.

| 파일 | 내용 |
|---|---|
| `lecture3.mp4` | 최종 영상 (1920×1080, 30fps, H.264 High CRF 14, AAC 48kHz 320k, 9:29.07) |
| `lecture3.srt` | 자막 357줄 (나레이션 348줄 + BEFORE/AFTER 영상 대사 9줄) |
| `timeline.md` | 슬라이드별 / 문장별 타임라인 |
| `chunks.txt` | 최종 스크립트 → 자막 줄 나누기 (` / ` 가 줄 경계, 이어 붙이면 스크립트 원문과 동일) |
| `vsubs.json` | BEFORE/AFTER 영상 대사 자막 (영상 시작 기준 초) |
| `scripts/` | 정렬·타임라인·렌더·QA 스크립트 |

## 파이프라인

1. PPT → LibreOffice PDF → 1920×1080 PNG (맑은 고딕 → Noto Sans KR 대체)
2. `check_chunks.py` — 자막 줄을 이어 붙인 결과가 스크립트 원문과 글자 단위로 같은지, 줄마다 25자 이내인지 확인
3. `asr.py` — FishAudio 음성 단어 단위 인식 (faster-whisper large-v3-turbo)
4. `align.py` — 스크립트 글자열 ↔ 인식 글자열 정렬, 각 자막 줄의 시작/끝 시간
5. `timeline.py` — 문장 경계를 실제 쉼(묵음/에너지 최저점)에 맞춤, `[2초 쉼]`·영상 삽입 지점에서 나레이션 분할, 슬라이드 전환은 해당 슬라이드 마지막 문장이 끝난 직후
6. `render.py` — 프레임 합성(슬라이드 + PPT 칸 그대로의 영상 + 자막) → x264, 오디오는 나레이션/영상 원음을 겹침 없이 이어붙임
7. `qa.py` — 슬라이드 순서, 문장·자막의 슬라이드 경계 침범, 자막 위치(y 971–1048), 자막 띠 아래 PPT 내용 유무 검사

## 자막 규격

Noto Sans KR Medium 54px, 흰색, 배경 검정 60%, 박스 높이 78px (y=971–1048), 좌우 여백 12px, 가로 중앙, 그림자·외곽선 없음, 위치 고정.
