# 사자의 태도 VSL 제작 프롬프트 (최종 정리본)

이 대화에서 입력한 요청을 시간 순서대로 모으고, 이후 수정 요청까지 반영해 하나로 합친 프롬프트입니다.
다음 VSL을 만들 때 파일 이름과 슬라이드 번호만 바꿔서 그대로 쓰면 됩니다.

## 2. 제작 지시 프롬프트

```
현재 자료를 기준으로 16:9 VSL 영상을 제작해줘.

이 작업의 최우선 기준은 첨부한 '최종 스크립트'다.
스크립트의 문장, 슬라이드 순서, 영상 재생 지시를 임의로 수정하거나 재해석하지 마라.

[목표]
새로운 VSL을 창작하는 작업이 아니다.
최종 PPT의 화면과 순서를 유지하면서 최종 스크립트에 맞춰
PPT 슬라이드, FishAudio 나레이션, PPT 속 영상, 준호님/동우님 후기 영상을
정확하게 타임라인에 배치해서 하나의 VSL 영상으로 완성한다.
PPT와 최종 스크립트가 다르게 보이면 문장과 재생 타이밍은 최종 스크립트를 우선한다.

114장을 1~114장까지 순서대로 진행한다.
슬라이드 114장, 이미지, 영상을 전부 눈으로 확인해서 일치하는 것을 활용한다.

[절대 규칙]
- 최종 스크립트 문장 수정 금지
- 문장 요약 금지
- 새로운 카피 추가 금지
- 슬라이드 순서 변경 금지
- PPT 텍스트 임의 수정 금지
- PPT 이미지 임의 교체 금지
- AI 이미지/AI 영상 임의 추가 금지
- FishAudio 대신 다른 TTS 생성 금지
- 문장 중간에서 나레이션을 잘라 붙이지 말 것
- 영상 원음과 FishAudio가 동시에 겹치는 구간을 만들지 말 것
- 최종 스크립트에 없는 묵음이나 긴 전환을 임의로 추가하지 말 것

[FishAudio 싱크]
FishAudio 나레이션은 슬라이드 번호가 없는 하나의 연속 음성이다.
최종 스크립트와 음성을 대조해서 각 문장이 어느 슬라이드에 해당하는지 타임라인을 만든다.
일반 슬라이드는
1. 해당 슬라이드를 보여주고
2. 그 슬라이드의 문장을 재생하고
3. 문장이 끝나는 타이밍에 다음 슬라이드로 넘긴다.
문장 중간에서 슬라이드를 넘기지 않는다.
대본, 자막, 음성, 슬라이드 전환 타이밍이 전부 정확히 일치해야 한다.

[A. 영상 원음만 재생 / FishAudio 정지]
6, 8, 11, 13, 15, 17, 19, 107
- 슬라이드에 들어가면 FishAudio를 멈추고 해당 영상을 원음과 함께 재생한다.
- 영상이 끝나면 다음 슬라이드부터 FishAudio를 이어서 재생한다.
- 영상 전후에 불필요한 묵음이나 긴 페이드를 넣지 않는다.

[B. 영상 화면 + FishAudio 계속]
53, 61, 72, 79, 89, 95 (하이에나/사자 영상)
4 (왼쪽 칸 5.mp4 하이에나, 오른쪽 칸 6.mp4 사자를 동시에 재생)
- 슬라이드가 뜨는 즉시 영상을 재생하고 FishAudio도 그대로 계속 재생한다.
- 영상의 원음은 쓰지 않고 화면만 쓴다. FishAudio가 메인 오디오다.
- 나레이션보다 영상이 짧으면 반복 재생하고, 길면 나레이션이 끝나는 시점에 넘긴다.
A와 B를 절대 혼동하지 마라.

[C. 105~109 후기 구간]
- 105: 세 가지 노하우 정리만 말한다. 후기 소개 문장은 말하지 않는다.
- 106: 106번 화면에서 FishAudio로
  "그럼 지금까지 제가 말씀드린 내용이 실제로 어떻게 적용됐는지,
   직접 코칭을 받은 분들의 이야기를 잠깐 들어보겠습니다."
  를 말하고, 끝나는 즉시 FishAudio를 멈추고 같은 106번 슬라이드에서
  준호님 후기 영상을 원음으로 재생한다.
- 107: 준호님 영상이 끝나면 멘트 없이 바로 107번으로 넘어가 동우님 후기 영상을 원음으로 재생한다.
  두 영상 사이에 긴 묵음이나 추가 문장을 넣지 않는다.
- 108: 동우님 영상이 끝나면 108번 화면에서 FishAudio를
  "그리고 이런 변화는 실제 만남에서도 결과로 이어지기 시작했습니다."부터 다시 재생한다.
- 109~114: 최종 스크립트대로 진행한다.

[슬라이드 전환]
- 컷, 매우 짧은 디졸브, 0.1~0.25초 크로스페이드만 사용
- 긴 페이드 투 블랙, 1초 이상의 화려한 전환, 3D 페이지 효과, 튕기는 효과, 쇼츠식 과한 모션 금지

[화면]
- PPT가 중심이다. 화려한 이미지나 모션그래픽은 넣지 않는다.
- 정지 슬라이드에는 필요한 경우에만 100% → 102~103% 정도의 아주 약한 줌을 쓴다.
- PPT 화면을 재디자인하지 않는다.
- 후기 카카오톡 이미지는 글씨가 읽히도록 원본 해상도를 유지한다.
- 106, 107 후기 영상은 크게 보여주되 PPT의 제목과 프레임은 훼손하지 않는다.
- 영상 오른쪽 상단에 '이다사'를 방해되지 않는 크기로 넣는다.
- PPT와 영상 어디에도 페이지 번호가 들어가지 않게 한다.

[오디오]
- FishAudio는 속도, 피치, 억양을 바꾸지 않는다.
- 영상 원음 구간과 FishAudio의 체감 음량을 비슷하게 맞추고 클리핑이 없게 한다.
- 배경음악과 효과음은 넣지 않는다.

[자막]
- 대본으로 읽히는 문장만 자막으로 넣는다. 슬라이드 구분 표시는 넣지 않는다.
- 하단에 노토산스 고딕체, 흰 글씨, 검은 배경 60% 정도.
- 자막 위치는 하단 한 곳에 고정하고 처음부터 끝까지 움직이지 않게 한다.
- 한 줄만 쓰고 25자를 넘기지 않는다.
- 온점, 반점은 넣지 않는다. 물음표와 따옴표만 필요한 곳에 넣는다.
- 의미 단위로 끊는다. 꾸며주는 말과 꾸밈을 받는 말을 떼지 않는다.
    예) 이분들에게 제가 가르친 건 / 특별한 멘트가 아니었습니다
    예) 물리적인 시간의 한계로 / 한 달에 딱 10명만 정밀 진단을 진행합니다
    예) 예를 들면 한 사람이 여자에게 다가가기 위해서
        방법과 수단을 가리지 않고
        모든 것을 해내기 위함입니다
- 자막 없이 나레이션만 넣는 슬라이드:
  58~60, 66~68, 76~78, 82~84, 91~93, 99~101
  단, 60, 68, 78, 93은 여자의 속마음 대사가 끝난 뒤 나오는 설명 문장부터 다시 자막을 넣는다.
    60: "이 남자 재미없다" 다음부터
    68: "와 이 남자 궁금하다" 다음부터
    78: "아 그냥 빨리 집에 가고 싶다" 다음부터
    93: "이거 내가 다 정해야 돼? 아 피곤하다" 다음부터
- 영상 재생 구간(A)과 후기 영상에는 자막을 따로 달지 않는다. 영상 원본 자막이 있으면 그대로 쓴다.
- 표기 수정:
    69: "카톡 답장 DM 올 때까지 폰을 놓지 못합니다"
    1:1 표기는 그대로 유지 ("1:1 진단을 신청하시기 바랍니다", "저와 1:1로 코칭을")

[출력]
- 16:9, 1920x1080, 30fps
- H.264 MP4, AAC 고품질 오디오
- PPT 글자가 흐려지지 않을 만큼 충분한 비트레이트

[작업 순서]
1. PPT 114장을 먼저 분석한다.
2. 최종 스크립트를 읽고 슬라이드별 나레이션과 영상 지시를 정리한다.
3. FishAudio 음성을 스크립트 문장과 매칭한다.
4. 전체 타임라인을 만든다. 슬라이드마다
   번호, 시작 시간, 종료 시간, FishAudio 사용 여부, 영상 재생 여부, 영상 원음 사용 여부를 정리한다.
5. A 구간(영상 원음 전용)과 B 구간(영상 + FishAudio)을 확인한다.
6. 105 → 106 브릿지 → 준호 영상 → 107 동우 영상 → 108 FishAudio 재개를 따로 검증한다.
7. 타임라인을 확인한 뒤 렌더링한다.
8. 렌더링 후 처음부터 끝까지 다시 검수한다.

[최종 QA]
1. 슬라이드 1~114 순서가 정확한가?
2. 스크립트 문장이 수정되거나 빠진 곳이 없는가?
3. FishAudio와 슬라이드가 한 장씩 밀린 구간이 없는가?
4. 6, 8, 11, 13, 15, 17, 19에서 FishAudio가 멈추고 영상 원음만 나오는가?
5. 4, 53, 61, 72, 79, 89, 95에서 영상과 FishAudio가 함께 나오는가?
6. 105에서 후기 소개 문장을 말하지 않는가?
7. 106 화면이 나온 뒤 "그럼 지금까지..." 문장이 나오는가?
8. 그 문장이 끝난 뒤 준호님 영상이 시작되는가?
9. 준호님 영상 동안 FishAudio가 완전히 꺼져 있는가?
10. 준호님 영상 직후 107 동우님 영상이 바로 나오는가?
11. 107에 FishAudio가 없는가?
12. 108에서 "그리고 이런 변화는..."부터 FishAudio가 다시 나오는가?
13. 후기 사진 슬라이드가 충분히 선명한가?
14. 114 CTA와 "감사합니다"까지 정상적으로 나오는가?
15. 영상과 음성 사이에 불필요한 긴 묵음이 없는가?
16. 자막 위치가 처음부터 끝까지 고정돼 있는가?
17. 자막이 25자 이내 한 줄이고 의미 단위로 끊겨 있는가?
```
