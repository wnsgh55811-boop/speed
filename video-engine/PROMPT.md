# 영상 제작 프롬프트 (붙여넣기용)

새 채팅을 열고 아래를 통째로 복사해서, 레퍼런스 영상 첨부 + 대본만 갈아끼우면 된다.

---

아래 대본으로 16:9 영상 만들어줘. 첨부한 영상을 레퍼런스로 해서 똑같은 퀄리티로 해줘.

## [기본 사양]
- 16:9 / 1920×1080 / 30fps / 1080p
- 전체 속도 1.2배속
- 제작 총괄: HyperFrames (로컬 CLI로 컴포지션 작성 → 렌더)
- 이미지 생성·목소리 전부 힉스필드(Higgsfield)로 (브라우저 열어서 작업)

## [스타일]
- 다크 차콜 배경 + 필름 그레인 느낌의 세련된 다크 무드 (레퍼런스와 동일)
- 네모 칸으로 막 하지 말고, 자연스럽고 고급지게
- 부드러운 느낌의 모션그래픽 + 픽토그램 + 인포그래픽 + 3D 아이콘 + 누끼딴 아이콘
- 키워드/핵심 문장은 화면에 크게 타이포로. **대사 그대로 적지 말고 요점만**
- 픽토그램·3D 아이콘·일러스트·인물 이미지·인포그래픽·모션그래픽을
  최대한 많이 활용해서 다채롭고 풍부하게. 밋밋한 타이포만 있는 장면 최소화
- 자막은 화면 하단에 (문장 단위, 싱크 정확하게)

## [목소리 — 힉스필드]
- 내가 저장해둔 **"내-목소리-v4"** 보이스 사용
- 모델은 일레븐랩스 말고 **Seed Audio 1.0**
- 설정: 표현 강도 5 / 무드 중립 / 피치 0 / 볼륨 100% / MP3 / 24kHz
- 속도 1.2배속 (TTS에서 1.2배로 뽑았으면 후처리에서 또 1.2배 걸지 말 것)
- 목소리 안 끊기고 전부 깔끔하게. 대본 길면 문단 단위로 잘라서 생성 후 이어붙이기

## [사운드]
- 효과음 막 넣지 말고, 모션그래픽/애니메이션 핵심 포인트에만 깔끔하게 몇 개만

## [절대 규칙 — 어기면 다시 작업]
1. **자막은 항상 한 줄.** 두 줄·세 줄로 넘어가면 안 됨.
   빌드 시점에 폰트 실측해서 미리 분할하고 `white-space:nowrap`으로 고정
2. **자막은 순백 + 얇은 검정 획**(`paint-order: stroke fill`). 어떤 배경에서도 읽히게
3. **중앙 타이포와 하단 자막이 같은 문장이면 하단 자막 제거.**
   중앙에 요점만 압축해서 띄운 경우엔 자막 유지 (겹치지만 않으면 됨)
4. **같은 이미지·같은 도식은 영상 전체에서 최대 2회.** 3회 이상 반복 금지
5. **배경은 여러 계열로 로테이션.** 같은 배경 3연속 금지.
   배경 위 워딩은 스크림 깔아서 WCAG AA 이상 대비 확보
6. **모든 시각 요소는 누끼 처리.** 배경 사각형 채로 올리지 말 것
   - 인물 이미지는 **겉에 흰색 종이 찢은 질감 테두리**를 남겨서 종이 카드처럼
     (단순 팽창 = 스티커처럼 보임 ✗ / 팽창 → 넓게 블러 → 노이즈 2옥타브 →
      하드 threshold 로 가장자리가 불규칙하게 흔들리도록)
7. **모든 요소는 가로·세로 정중앙 정렬.** 아래로 치우치거나 프레임 밖으로 잘리면 안 됨
8. **이미지는 충분히 밝게.** 텍스트만 보이고 사진이 검은 사각형으로 죽으면 안 됨
   (어둡게 하는 처리를 여러 개 겹치지 말 것 — 다크 무드는 배경으로 잡고 사진은 살릴 것)
9. **그래프는 길이만 그리지 말고 "정도"를 표시.**
   등급 점·눈금·축 라벨을 넣어서 얼마나 깊은지/많은지가 읽히게
10. 인용 말풍선에는 **말한 내용을 반드시 적을 것.** 화자 이름만 있으면 화면이 안 읽힘
11. 취소선·엑스 표시는 **대상 위에 적당한 크기로.** 프레임을 가로지르게 키우지 말 것

## [작업 방식]
- 토큰 아끼면서 작업해줘
- 자동으로 끝까지 진행. 중간에 계속 묻지 말 것
- **최종 렌더 전에 반드시 프리뷰를 보여줄 것**
- 단, 아래 3개는 토큰 아끼더라도 **실제 프레임을 캡처해서 눈으로 확인**하고 넘어갈 것:
  ① 자막 한 줄 유지  ② 인물·아이콘 누끼와 중앙 정렬  ③ 그래프가 실제로 그려지는지
  (코드가 맞아 보여도 화면에 안 나오는 버그가 있음 — 예: `<i>`는 인라인이라
   width/height가 안 먹어서 막대그래프가 통째로 안 그려짐)

## [결과물 전달]
- **최종본은 MP4 링크로 줄 것.** 클릭하면 바로 재생되고,
  **로그인·권한 승인·클레임 같은 절차가 필요 없어야 함**
- 소리(나레이션)가 반드시 들어가 있을 것
- 용량 큰 원본과 별개로, 브라우저에서 바로 열리는 100MB 내외 경량본도 같이

## [렌더 시 주의사항]
- 오디오 파일은 **렌더 시작 전에 미리 완성**해 둘 것.
  컴포지션이 참조하는 오디오가 없으면 렌더가 곧바로 실패함
- 나레이션 길이를 **자막 타이밍 기준 길이에 정확히 맞출 것.**
  다시 합치면 1초 내외로 어긋나므로 atempo 미세 보정으로 맞춤
  (0.2% 수준이라 귀로는 안 들림)
- 원격 샌드박스에서 렌더할 경우 **끝날 때까지 계속 붙어서 폴링할 것.**
  잠깐이라도 놓으면 컨테이너가 회수되면서 렌더가 통째로 날아감
