# 이다사 VOD 1강 — PPT 강의 영상 빌드

입력(구글 드라이브): `1강 PPT.pptx`, `1강 음성.wav`(FishAudio), `1강 하이에나의 태도.mp4`, `1강 사자의 태도.mp4`, `이다사_VOD_1강_최종스크립트.txt`.
`S` = 작업 폴더 (`S/dl/1강/` 에 원본, `S/slides/s-NN.png` 에 슬라이드, `S/work/` 에 이 폴더 파일).

1. 슬라이드: `soffice --convert-to pdf` → `pdftoppm -scale-to-x 1920 -scale-to-y 1080` (맑은 고딕 → Noto Sans CJK KR 대체)
2. `subs.txt`: 최종 스크립트를 의미 단위 자막(25자 이내 한 줄)으로 나눈 것. `python3 parse.py S` 로 원문과 글자 단위 일치 검사
3. `asr.py`: Whisper 단어 타임스탬프 → `align.py S`: 스크립트 글자↔음성 정렬 + 실제 쉼 구간으로 경계 보정
4. `timeline.py S`: 슬라이드 전환(문장 사이 쉼 중앙), 슬라이드 11 영상 삽입(나레이션 정지, 원음 재생)
4-1. 슬라이드 11: FishAudio 테이크에 있는 '이번에는 다른 반응을 보겠습니다'(스크립트에 없음)는 요청에 따라 AFTER 영상 직전에 배치
5. `render.py S out.mp4`: H.264 CRF14 / AAC 320k / 1920x1080 30fps, 자막 하단 고정(흰 글자 54px + 60% 검정 박스, 박스 높이 78px 유지)
