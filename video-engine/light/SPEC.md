# 밝은 미니멀 인포그래픽 영상 — 제작 사양 (레퍼런스: 유튜브 마케터 제이 영상 1)

기존 `video-engine/`(다크·HyperFrames·TTS)과는 별개의 파이프라인이다.
녹음된 음성 + 대본 → Playwright 프레임 렌더 → ffmpeg 합성.

## 0. 요약
음성 + 대본 → 1920×1080 30fps 유튜브 영상. 오프화이트 격자 배경 위 인포그래픽·UI·밈,
챕터 타이틀 카드 + 상단 챕터 진행바, 하단 중앙 자막(한 화면 한 문장 이내).
효과음·BGM·화면전환·등장 애니메이션 없음(막대그래프 0.9초 성장만 예외).

## 1. 출력
- 영상: 1920×1080, 30fps, H.264 yuv420p CRF 20 + AAC 192k, 음성 원본 그대로
- 썸네일 1280×720 PNG
- 챕터 타임스탬프(실제 음성 기준, 첫 줄 0:00)
- 결과물은 레포에 커밋·푸시

## 2. 음성·싱크
- 드라이브 폴더 링크 → `gdown --folder`. 음성 편집 금지.
- faster-whisper `large-v3-turbo`, ko, word_timestamps, beam 5, initial_prompt=대본 앞부분
- 자막 텍스트 = 대본 원문, 인식 결과는 타이밍에만. difflib 글자 정렬로 줄별 start/end
- 시작점 = RMS(10ms) onset 스냅: 무음 뒤 줄은 다음 onset, 나머지는 ±0.15s 내 onset. 자막 0.03s 선행
- 다음 줄과 간격 < 0.6s → 유지, 이상 → end+0.2s에 내림
- 녹음≠대본 단어는 녹음 기준으로 고치고 보고

## 3. 자막
- 하단 중앙, top≈880px. 박스 #141414 94%, r14, 흰 글자 Gothic A1 Bold 56px, lh1.3, max-w 1500, keep-all
- 한 화면 ≤ 한 문장, 12~28자, 최대 2줄. 쉼표·구·절 단위로 분할
- 마침표 제거, 따옴표·물음표 유지. `**강조**`·결론 문장은 주황 박스 #FF5A1F
- 폰트: Gothic A1(500/700/900) + Noto Color Emoji만

## 4. 디자인 토큰
| 토큰 | 값 |
|---|---|
| 배경 | #F5F3EE + 90px 격자(검정 3.5%) |
| 잉크 / 회색 / 선 | #141414 / #8C877E / #E4DFD5 |
| 주황 / 초록 | #FF5A1F / #12A150 |
| 카드 | 흰색, r26, `0 14px 40px rgba(0,0,0,.08)`, 2px #EEEAE2 |
| 강조 카드 | 검정 + 흰 글자 + 주황 포인트 |
| 섹션 제목 | 주황 세로 막대 + 44px |
| 콘텐츠 영역 | 중심 y=505, 1740×640 |
- 미등장 요소는 opacity .18로 자리 잡고, 나레이션이 말하는 순간 켠다

## 5. 헤더
- (90,46) 검정 라벨 `CHAPTER n` + 제목 38px, 아래 챕터 수만큼 진행바(지난=검정, 현재=주황, 남은=회색)
- 오프닝·챕터 카드 동안 숨김. 마무리 구간 라벨은 `OUTRO`

## 6. 챕터 타이틀 카드
- 라디얼 #232220→#121212, 전부 중앙, 블록 하단 패딩 170px
- `—— CHAPTER ——` 26px 자간12 #9C958A Medium, 양옆 70px #4a4742 선
- 번호 01~ 150px Medium 주황 자간4 / 56×3 흰35% 선 / 제목 78px Bold 흰색 한 줄
- 챕터 첫 문장에서 띄우고 다음 문장에서 본문으로. 1초 미만이면 한 문장 더 유지
- 마무리 구간은 카드 없이 "오늘의 정리"

## 7. 장면 구성
- 문장/문단마다 장면 1개(7분 ≈ 70~80장면), 문장 시작과 동시에 컷
- 세부 요소(목록·비교 오른쪽·표 칸·말풍선·체크)는 해당 단어 발화 시점에 켬
- `[화면]` 그대로 제작, `(예시)` → 제목에 "(예시)". 실제 아이디·개인정보 금지(회색 막대)
- 비율: 인포그래픽·UI 80% / 밈 15% / 큰 문구 5~10%

## 8. 컴포넌트
lock(무엇/왜/어떻게 타일) · list · vs(≠ = + or) · table(3열, 칸별 등장, 이긴 쪽 주황) ·
flow(→, 마지막 검정, 하단 연주황 메모) · big(92px + 검정 t2 박스, ✕/○) · comments(인스타 UI) ·
dm(📭 문의 0건) · profile(그리드 + 초록 배지) · bars(0.9s 성장) · branch(검정 말풍선 + 3카드 + 주황 해결 라벨) ·
grid(사람×1~5칸, ✓초록/✕연주황) · example(무료=흰 초록태그 / 유료=검정 주황태그) ·
caption(BEFORE 회색/AFTER 초록, 줄 단위, 결론 주황) · thread(질문 → 취소선 ✕ 답 → 검정 ○ 답) ·
check(체크박스 + 주황 → 결과) · end(💬 검정 알약 + 빨강 구독 알약)

## 9. 밈

- 흰 테두리 8px, r18, 그림자, 1100×540 안 비율 유지. 위에 ‘ ’ 캡션 44px(속마음)
- 영상 내 재사용 금지, 드레이크 금지, 감정·반응 순간에만
- 기존 사용: tip hat, Ight imma head out, 해골 대기, 수학 계산 여인, This is fine, 잠옷 소년,

## 11. 썸네일 1280×720
- 같은 배경. 좌: 검정 태그 → 3줄 헤드라인 88px Black(핵심 2~4자 비스듬한 주황 형광펜+흰 글자, lh≥1.3) → 회색 부제
- 우: 핵심 구조 카드 3장(마지막 검정 강조)

## 12. 렌더
타임라인 JSON(자막·장면·챕터·요소 등장시각) → HTML 템플릿 1장 → Playwright 1920×1080 `renderAt(t)` →
30fps JPEG q93 → ffmpeg + 원본 음성 → MP4 → 여러 시점 프레임 검수(겹침·잘림·빈 화면)

## 레퍼런스 실측 메모 (7:02, 1920×1080 30fps, 6챕터 + OUTRO)
- 헤더 진행바: 7칸(6챕터+OUTRO), 칸 폭 ≈240px, 간격 ≈10px, 높이 ≈6px, y≈122. 라벨 박스 ≈ 217×54, r10
- 자막 박스: 패딩 ≈ 좌우 34px / 상하 14px, 하단 y≈985. 한 줄 우선, 길면 2줄
- 섹션 제목은 카드 바로 위 중앙 정렬(주황 막대 ≈10×44)
- 목록: 행 높이 ≈128, 폭 ≈1300, 번호 원 78px(비활성 #E8E4DC/활성 주황), 현재 행만 검정
- 표: 카드 폭 ≈1500, 행 높이 ≈80, 항목명 회색 36px, 값 40px Bold, 결과값 주황
- 오프닝: 첫 화면부터 lock 타일 → "오늘 다룰 내용" 목록 → 챕터 01 카드
- 마무리: "오늘의 정리" 목록 → 큰 비교 → end 알약
- 장면 컷은 문장 경계와 정확히 일치, 페이드 없음
