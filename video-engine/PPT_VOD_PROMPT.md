# PPT 강의 VOD 제작 원칙 (붙여넣기용)

PPT + FishAudio 나레이션 + 최종 스크립트로 "PPT를 넘기면서 말하는" 강의 영상을 만들 때 쓰는 프롬프트.
1강(`examples/lecture1/`) 제작 때 준 지시와 수정 요청을 한 번에 정리했다. 새 강의는 아래를 통째로 붙여넣고
[자료] 칸만 바꾸면 된다.

---

[자료]
- 구글 드라이브: (폴더 링크)
- PPT: (N강 PPT.pptx)
- 최종 스크립트: (이다사_VOD_N강_최종스크립트.txt)
- FishAudio 음성: (N강 음성.wav)
- PPT 속 영상: (있으면 파일명과 들어갈 슬라이드)

이 자료로 PPT를 넘기면서 말하는 16:9 VOD 강의 영상을 만들어줘.
대본은 최종 스크립트 속 내용으로 하되, 슬라이드 표시 같은 것은 자막에 넣지 마.

이 작업의 최우선 기준은 첨부한 '최종 스크립트'다.
스크립트의 문장, 슬라이드 순서, 영상 재생 지시를 임의로 수정하거나 재해석하지 마라.

## [목표]
PPT의 화면과 순서를 유지하면서 최종 스크립트에 맞춰
PPT 슬라이드, FishAudio 나레이션, PPT 속 영상을
정확하게 타임라인에 배치해서 하나의 강의 영상으로 완성한다.
PPT와 최종 스크립트가 다르게 보이면 문장과 재생 타이밍은 최종 스크립트를 우선한다.

## [절대 규칙]
- 최종 스크립트 문장 수정 금지
- 문장 요약 금지
- 새로운 카피 추가 금지
- 슬라이드 순서 변경 금지
- PPT가 자연스럽게 넘어가면서 대본과 음성을 일치시켜 이야기하면 된다
- PPT 텍스트 임의 수정 금지
- PPT 이미지 임의 교체 금지
- AI 이미지/AI 영상 임의 추가 금지
- FishAudio 대신 다른 TTS 생성 금지
- 문장 중간에서 나레이션을 잘라 붙이지 말 것
- 영상 원음과 FishAudio가 동시에 겹치는 구간을 만들지 말 것
- 최종 스크립트에 없는 묵음이나 긴 전환을 임의로 추가하지 말 것

## [FishAudio 싱크]
FishAudio 나레이션은 슬라이드 번호가 없는 하나의 연속 음성이다.
최종 스크립트와 음성을 대조해서 각 문장이 어느 슬라이드에 해당하는지 타임라인을 만든다.
일반 슬라이드는
1. 해당 슬라이드를 보여주고
2. 그 슬라이드의 문장을 재생하고
3. 문장이 끝나는 타이밍에 다음 슬라이드로 넘긴다.

문장 중간에서 슬라이드를 넘기지 않는다.
대본, 자막, 음성, 슬라이드 전환 타이밍이 전부 정확히 일치해야 한다.

- FishAudio에 스크립트에 없는 문장이 녹음돼 있으면 빼거나 다른 문장에 묻지 말고,
  나에게 알려준 뒤 자막을 따로 달아서 맥락에 맞는 자리에 둔다.
  (1강 예: "이번에는 다른 반응을 보겠습니다" → AFTER 영상 직전에 말하고 영상 재생)

## [PPT 속 영상]
- 스크립트의 영상 지시 위치(예: "위 대본 이후 BEFORE 영역 밑에 영상 재생")에서 FishAudio를 멈추고 영상을 재생한다.
- 영상은 PPT에 들어 있는 그 칸의 위치와 크기 그대로 재생한다.
- 영상 구간은 영상 원음만 나온다. FishAudio와 겹치지 않게 한다.
- "영상 끝나자마자 피쉬 음성"이면 영상이 끝나는 즉시 다음 나레이션을 시작한다.
- 영상 원음 음량은 나레이션 음량에 맞춘다.
- 영상 재생 구간에도 자막을 달아준다 (영상 속 대사).

## [자막]
- 화면 하단, PPT 속 텍스트와 겹치지 않게
- 위치 고정, 처음부터 끝까지 이동 없음
- 항상 한 줄, 25자 이내
- 의미 단위로 끊는다. 꾸며주는 말과 꾸밈을 받는 말을 떼지 않는다.
    예) 이분들에게 제가 가르친 건 / 특별한 멘트가 아니었습니다
    예) 물리적인 시간의 한계로 / 한 달에 딱 10명만 정밀 진단을 진행합니다
    예) 예를 들면 한 사람이 여자에게 다가가기 위해서
        방법과 수단을 가리지 않고
        모든 것을 해내기 위함입니다
- 스타일 (1강 확정값, 1920×1080 기준):

  | 항목 | 값 |
  |---|---|
  | 글꼴 | Noto Sans KR Medium (깔끔한 고딕) |
  | 글자 크기 | 54px |
  | 글자 색 | 흰색 |
  | 배경 | 검정 60% 불투명 박스 |
  | 배경 높이 | 78px (글자 위아래 여백 12px) |
  | 배경 가로 | 자막 글자 폭 + 좌우 여백 12px씩 |
  | 위치 | 가로 정중앙. 박스 윗변 y=971, 아랫변 y=1048 (화면 하단에서 32px 위) |
  | 그림자/외곽선 | 없음 |

  ASS로 넣을 때: `Fontsize 54, BorderStyle 3, Outline 12, Shadow 0, OutlineColour &H66000000`,
  각 줄 `{\an2\pos(960,1037)}`.

## [출력]
- 16:9, 1920×1080, 30fps
- H.264 MP4, AAC 고품질 오디오
- PPT 글자가 흐려지지 않을 만큼 충분한 비트레이트
- 완성본은 바로 재생되는 링크로 줄 것 + 원본 화질 MP4 파일도 같이

## [작업 순서]
1. PPT를 먼저 분석한다.
2. 최종 스크립트를 읽고 슬라이드별 나레이션과 영상 지시를 정리한다.
3. FishAudio 음성을 스크립트 문장과 매칭한다.
4. 전체 타임라인을 만든다. 슬라이드마다
   번호, 시작 시간, 종료 시간, FishAudio 사용 여부, 영상 재생 여부, 영상 원음 사용 여부를 정리한다.
5. 타임라인을 확인한 뒤 렌더링한다.
6. 렌더링 후 처음부터 끝까지 다시 검수한다.

## [최종 QA]
1. 슬라이드 순서가 PPT와 정확히 같은가?
2. 스크립트 문장이 수정되거나 빠진 곳이 없는가?
3. FishAudio와 슬라이드가 한 장씩 밀린 구간이 없는가?
4. 영상 슬라이드에서 FishAudio가 멈추고 영상 원음이 나오는가?
5. 영상과 음성 사이에 불필요한 긴 묵음이 없는가?
6. 자막 위치가 처음부터 끝까지 고정돼 있는가?
7. 자막이 25자 이내 한 줄이고 의미 단위로 끊겨 있는가?
8. FishAudio에 스크립트에 없는 문장이 있었다면 보고하고 자막을 달았는가?
