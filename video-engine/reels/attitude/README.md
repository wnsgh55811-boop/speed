# 릴스: 태도를 바꾸면 연애가 쉬워진다 (9:16 · 1080×1920 · 30fps · 67.94s)

`REELS_STYLE.md` 규칙으로 만든 세로 릴스. HTML/SVG + GSAP 컴포지션을 Playwright로 프레임 캡처해서 렌더한다.
원본 음성은 길이·속도·타이밍을 건드리지 않고 그대로 깔고, 그 위에 합성 효과음(26개, -13dB 이하)만 섞는다.

## 파이프라인
1. `ko_asr.py` — sherpa-onnx 한국어 zipformer로 토큰 타임스탬프 추출 (HF가 막혀 있어서 GitHub 릴리스 모델 사용)
2. `align.py` — `script.txt`의 줄바꿈 단위로 대본과 ASR을 정렬해 `lines.json` 생성 → `lines.js`
3. `main.js` — 장면 25개 타임라인 (줄 인덱스 `T(i)`로 음성에 고정). `art.js`는 캐릭터·아이콘 SVG
4. `snap.js` / `sheet.sh` — 특정 시점 프레임 캡처 + 컨택트 시트로 검수
5. `full.sh` — 4개 워커 병렬 렌더 → concat → 음성+SFX 믹스 (`sfx.py`)

```
npm i gsap pretendard @fontsource/gaegu
python3 -m http.server 8123 &      # 이 폴더에서
./full.sh                           # ../out/reels.mp4 (마스터, crf14)
```
`full.sh`는 `../src.mp4`(원본 음성 파일)를 읽는다.

## 장면 구성
Hook(매력 게이지 깎임) → 흔한 착각(말주변·유머 ✕) → **진짜 원인**(반응 다이얼 vs 태도 다이얼) →
예시①소개팅 해명 → 예시②농담 수습(웃음 게이지·되돌리기) → 카톡 인서트/UI(짧은 답장→과한 친절, 늦은 답장→새 화제 투척) →
배려? → **반전**(프리즈·취소선·돋보기로 '불안' 공개, 1% 무게추) → 신호 감시·"나_진짜최종(7).hwp" →
하이에나(꼭두각시 줄) → 사자(반응은 본다 / 선 넘으면 사과 / 깃발=기준 유지 / 사자의 대화) → 이 차이 ≠ →
필터·실수↓·내가 사라짐 → 셀프 체크 → 멘트 ✕ → 흔들리는 반응 vs 유지되는 태도 → 핵심 메시지 → 좋은 사람 vs 이성 → CTA
